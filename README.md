# 광고 만들기 · 통합 대시보드

광고 소재를 만드는 13가지 "자판기"를 한 화면에 모은 정적 웹앱입니다.
설치·로그인·서버 없이 브라우저에서 바로 동작하며, 입력한 내용은 서버로 전송되지 않고
사용 중인 브라우저(localStorage)에만 저장됩니다.

**라이브:** https://sabsab762-ai.github.io/ad-maker/

## 상세페이지 자동 읽기는 어떻게 동작하나

정적 페이지는 브라우저 보안(CORS) 때문에 남의 사이트를 직접 읽지 못합니다. 그래서:

1. **리더 A · r.jina.ai** — 페이지를 본문(Markdown)으로 변환해 주는 공개 리더. CORS 허용.
2. **리더 B · api.allorigins.win** — 원본 HTML을 대신 받아 주는 공개 프록시.
3. **리더 C · api.cors.lol** — 같은 역할의 두 번째 프록시.

세 경로를 차례로 시도하고, 읽은 본문이 120자 미만이거나 "접속 차단·에러페이지" 문구가 보이면 실패로 처리합니다.
스마트스토어·쿠팡·동행복권처럼 로그인/봇 차단이 강한 곳은 세 경로 모두 거절될 수 있어,
그때는 **본문 붙여넣기** 또는 **캡처 이미지 등록**으로 같은 분석을 이어갑니다.
(캡처는 분석 카드·컨닝페이퍼 원본 이미지로 쓰입니다.)

## 참고

- **AI 영상**은 실제 영상 파일을 렌더링하지 않습니다. 외부 유료 API가 필요한 부분이며, 이 앱은 촬영·생성에 바로 쓰는 대본과 프롬프트, 스토리보드를 만들어 줍니다.
- **로또 영상**은 캔버스 + MediaRecorder로 실제 WebM 파일을 만듭니다(10·15·20·30초). 브라우저가 녹화를 지원하지 않으면 화면 PNG를 쓰세요. 아이폰 사진첩에 넣으려면 파일 앱에서 열거나 PC에서 MP4로 변환합니다.
- **인스타 "AI 사진"**은 실제 이미지 생성이 아니라, 올린 사진을 배경으로 쓰거나 글자만으로 표지를 그립니다.
- **사이트 분석**이 뽑는 "고객 3명·소구점 5개"는 페이지 문장에서 규칙으로 만든 제안입니다. 실제 고객 조사 결과가 아닙니다.
- 로또 당첨 데이터: 동행복권 공개 회차 결과를 정리한 cashlogy.kr 데이터셋(CC BY 4.0) 최근 104회.
- **사주 자판기**는 태양 황경으로 24절기를 계산해 월주를 정하고, 1900-01-01 갑술일 기준 60일 순환으로 일주를 계산합니다(재미·콘텐츠용).
- 상단 **데이터 백업**으로 localStorage 내용을 JSON 한 파일로 내려받을 수 있습니다.

## 구조

빌드 도구 없이 동작하는 단일 파일 앱입니다.

```
index.html        # 배포본 (CSS + JS 인라인)
src/shell.html    # 마크업 + 스타일 템플릿
src/core.js       # 라우터·저장소·공통 UI
src/lib-ads.js    # 공용 엔진: 페이지 읽기/분석/보관함/카피/캔버스
src/data-lotto.js # 로또 최근 104회 당첨 데이터
src/mod-*.js      # 자판기 모듈 13종
build.py          # src → index.html 조립
```
