# 광고 만들기 · 통합 대시보드

광고 소재를 만드는 9가지 "자판기"를 한 화면에 모은 정적 웹앱입니다.
설치·로그인·서버 없이 브라우저에서 바로 동작하며, 입력한 내용은 서버로 전송되지 않고
사용 중인 브라우저(localStorage)에만 저장됩니다.

**라이브:** https://sabsab762-ai.github.io/ad-maker/

## 9개 자판기

| # | 기능 | 하는 일 |
|---|------|--------|
| 1 | 🥕 당근 광고 자판기 | 혜택 카드 등록·일괄 등록 → 홍보글 3종 생성 → 배포용 HTML 내보내기 |
| 2 | 📸 인스타 캐러셀 사진 자판기 | 주제·장수·테마로 1080×1350 카드뉴스 슬라이드 생성, 슬라이드별 PNG 저장 |
| 3 | 🧵 스레드 대본 자판기 | 주제·타겟·톤으로 공감형·반전형·리스트형·썰형 대본 4종 생성 |
| 4 | 🎱 로또 자판기 (무료) | 1~45 번호 5게임, 고정수·제외수·홀짝/고저 밸런스, 이력 저장 |
| 5 | 🎬 AI 영상 만들기 | 쇼츠/릴스 대본 + 컷별 영문·한글 프롬프트 + 자동 재생 스토리보드 |
| 6 | ☕ 카페 글쓰기 자판기 | 후기·질문·정보·핫딜형 글 생성 + 광고성 금칙어 체크 |
| 7 | 🥷 광고 컨닝페이퍼 | CPA·로컬매장·커머스·앱설치별 헤드라인·공식·CTA 40종 + 내 문구 저장 |
| 8 | 🔍 사이트 분석하기 (무료) | 붙여넣은 랜딩페이지 카피를 100점 채점·개선점 제안 + URL 분석 요청 문구 |
| 9 | 🛍️ 상세페이지 자판기 | 상품 정보로 모바일 상세페이지 실시간 미리보기 + 완성 HTML 다운로드 |

## 참고

- **AI 영상**은 실제 영상 파일을 렌더링하지 않습니다. 외부 유료 API가 필요한 부분이며,
  이 앱은 촬영·생성에 바로 쓰는 대본과 프롬프트, 스토리보드를 만들어 줍니다.
- **사이트 분석**은 브라우저의 CORS 정책 때문에 외부 사이트 HTML을 직접 읽지 못합니다.
  본문을 붙여넣어 분석하거나, 김호퍼에게 URL 분석을 요청하는 문구를 복사해 쓰세요.
- 상단 **데이터 백업**으로 localStorage 내용을 JSON 한 파일로 내려받을 수 있습니다.

## 구조

빌드 도구 없이 동작하는 단일 파일 앱입니다.

```
index.html      # 배포본 (CSS + JS 인라인)
src/shell.html  # 마크업 + 스타일 템플릿
src/*.js        # 기능 모듈 (core + 9종 자판기 + init)
build.py        # src → index.html 조립
```
